## 🧪 **ПРОТЕСТОВАНІ СЦЕНАРІЇ**

### **✅ Адаптивність:**
1. **Десктоп (>1024px)**: 3-колонкова сітка, нормальні картки
2. **Планшет (768-1024px)**: 2-колонкова сітка, нормальні картки  
3. **Широкі картки (480-768px)**: 2-колонкова сітка, але картки в 2 колонки
4. **Мобільний (<480px)**: 1-колонкова сітка, адаптивні висоти заголовків

### **✅ Пошук:**
- "щебінь 5-10" → знаходить "Щебінь гранітний 5-10"
- "піщана суміш" → знаходить "Щебенево-піщана суміш"
- "річковий" → знаходить "Пісок річковий"

### **✅ Фільтрація пунктів:**
- Щебінь → 7-9 пунктів (залежно від товару)
- Пісок річковий → 3 пункти (тільки роздрібні бази)
- Пісок яружний → 3 пункти (тільки роздрібні бази)

### **✅ UX:**
- Заголовки синхронізовані по висоті в картках
- Фракції не розриваються між рядками
- Кнопки "Назад" працюють з обох місць
- Альтернативний текст зображень центрований
